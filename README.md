# Gao Bin — Academic Homepage

This version is populated from the supplied CV.

## Deploy
1. Create a GitHub repository named `YOURUSERNAME.github.io`.
2. Upload all files in this folder to the `main` branch.
3. Edit `_config.yml` and replace `YOURUSERNAME`.
4. In **Settings → Pages**, choose **GitHub Actions**.
5. The included workflow will build and deploy the Jekyll site.

## Before publishing
- Replace the placeholder paper links marked `#`.
- Export your CV to PDF and save it as `assets/pdf/Gao-Bin-CV.pdf`.
- Add your Google Scholar / ORCID links when ready.
- Optionally add a profile photo at `assets/img/profile.jpg` and update the hero section.
